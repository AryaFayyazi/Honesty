# Preregistration v49: all four models in every main experiment, and the intervention-choice hypothesis

Written 2026-10-04 ~23:05, before any v49 rollout exists. Models: Qwen3.8-27B, Muse-Glimmer-30B, Gemma-4-26B-A4B,
gpt-oss-20b.

## Why
- Several main results so far cover only some models. Laundering/F1 used 3 models; v40/v45 used Muse only; steering
  v39–v48 used Muse only.
- v44/v45 suggested that the effect of an accountability prompt (the evidence contract) depends on whether the agent
  internally represents its violation.
- The authors require every main experiment to include all four models.

## Fresh data (none exists now; fixed harness)
- **Muse.** v47 stage-1 sets (shared, already queued).
- **Gemma-4, gpt-oss-20b.** Fresh x− rollouts: core24b seeds 6–9; core24b_reasoning seeds 6–9.
- **Qwen3.8.**
  - Fresh x− rollouts: core24b seeds 2–5, and core24b_reasoning and core24b_obfuscate seeds 0–3 (Qwen has never been
    run on the variants).
  - The server harness gains a Qwen3.8 actor (vLLM 0.26 configuration matching the original Qwen rollouts:
    language-model-only, triton GDN prefill, thinking on).
  - A smoke test must reproduce Qwen's core24b behaviour (violation rate within ±5 pts of the original
    seeds 0–1) before the fresh runs count. Otherwise the configuration is fixed first.
- **Labels and features.** Rubric v4; pre-report features (scripts/94); action features (scripts/56).

## H1 (primary): internal knowledge predicts which intervention helps
- **Internal knowledge index K.** Decode-positive rate at informed violations, measured before v49 (core24; recorded
  in docs/xm_findings.md and the summary): **Muse 0.94 > Qwen 0.81 > Gemma 0.69 > gpt-oss 0.03**.
- **Effect B.** Per model, on fresh informed episodes: B = lie(neutral) − lie(fta_contract). Both generated by
  scripts/96 with the same seed per episode; paired; complete-case.
- **Prediction.** B is ordered as K: Muse > Qwen > Gemma > gpt-oss. In particular, Qwen's benefit lies between Muse's
  and Gemma's, and gpt-oss's B < 0 (backfire).
- **Tests:**
  - (a) the exact permutation test of the predicted complete order (p = 1/24 = 0.042 if exactly matched);
  - (b) Spearman ρ(K, B) > 0;
  - (c) gpt-oss B < 0 (McNemar one-sided).
  - H1 PASSES if (a) holds, i.e. the exact order, or if ρ ≥ 0.8 with (c).
  - Per-model B with 95% CIs is always reported.

## H2: the pre-report internal forecast, per model
- For each model, internal and text forecasters are frozen before its fresh data exists, trained on all existing
  labelled episodes of that model (the v47 recipe).
- **E1(model):** internal > 0.5. **E2(pooled):** internal > text, pooled with per-model z-scores.
- Holm over the four E1 tests. The Muse E1/E2 are those of v47 (shared).

## H3: targeted vs blanket, per model (secondary)
- T = contract iff the frozen internal forecaster fires (LDA decision > 0), versus C (blanket) and N (none).
- **Prediction from H1:** for models with B > 0 (blanket helps), C ≤ T. For gpt-oss (B < 0), T < C.
- Descriptive with McNemar statistics.

## H4: internal steering for every model
- Each model gets its own CAA development sweep (paired honest/lying regenerated reports of that model, from v37 P,
  v44 and v49 regenerations) and a locked confirmation on its fresh v49 episodes. The design is v43/v48's: guards,
  degradation guard, random control.
- A separate dated addendum per model, written before that model's confirmation generation.

## Reporting
All four models appear in every main table. A model with too few informed lies for a test (fewer than 15 lies or
non-lies) is reported descriptively, with that reason stated.
